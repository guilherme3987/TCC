\chapter{Objetivos}
\label{ch:objetivos}

Este estudo tem como objetivo primário relacionar os pilares do \gls{pc} com as questões de matemática do \gls{enem} para desenvolver e avaliar um sistema gamificado, fundamentado nesses pilares, para engajar estudantes do Ensino Médio. 

Os objetivos secundários consistem em: Avaliar a experiência dos estudantes da \gls{upt}, com base na metodologia DBR utilizando escala de amostragem de experiência \gls{esm} e engajamento do usuário \gls{ues}.
